# Demo Apps

Small, self-contained working apps that demonstrate AI-native PM patterns. The rule here is simple: it has to actually run. A 200-line working thing beats a 2,000-line scaffolded thing that doesn't.

Each app has a "what this shows" paragraph and a "run it" section in its own README.

## Build philosophy

These apps are kept intentionally small. The goal isn't to build production software — it's to show a working pattern that a PM can understand, fork, and adapt. If it takes more than five minutes to get running, it's too complex.
