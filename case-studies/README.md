# Case Studies

Anonymised walkthroughs of how I've used AI agents on real PM work. The point isn't to show impressive outputs — it's to show the process: what I delegated, how I prompted, where it broke down, what I had to fix, and what I learned.

These are honest, not polished.

## Anonymisation approach

All case studies strip employer context completely. The patterns and workflows are real; the domain framing is kept generic (consumer fintech, identity/auth). If something can't be described without identifying a specific org, it doesn't go in.
